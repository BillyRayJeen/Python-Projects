Username & Password Simulator

A simple Python-based IT support simulation designed to resemble a basic password reset process commonly handled by a first-line IT support/service desk team.

The program generates a random username, allows the user to request a password reset, asks for confirmation, and generates a new random temporary password when the reset is approved.

Current Features

* Generates a random username
* Masks the current password when displayed
* Allows the user to request a password reset
* Uses confirmation before changing the password
* Generates a random 12-character temporary password
* Includes letters, numbers and symbols in generated passwords
* Allows the user to cancel the reset request

Purpose

This project was created as part of my self-directed Python and IT support learning. It demonstrates how basic programming can be used to simulate a common first-line IT support task while developing an understanding of user verification, confirmation and password reset workflows.
